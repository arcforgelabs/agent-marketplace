# Simplified Technical English: the working rules

Simplified Technical English (ASD-STE100) is a controlled language for technical text. Every explainer page, pop-up, label and reply uses these rules. The source is the public specification at asd-ste100.org.

## Limits

| Text | Limit |
| --- | --- |
| Procedural sentence (an instruction) | 20 words or fewer |
| Descriptive sentence | 25 words or fewer |
| Paragraph | 6 sentences or fewer, one topic |
| Noun cluster | 3 words or fewer |
| Instructions in one sentence | 1 (except actions that occur at the same time) |

## Verb forms

| Form | Example | Status |
| --- | --- | --- |
| Command | Close the valve. | Approved |
| Simple present | The valve closes. | Approved |
| Simple past | The valve closed. | Approved |
| Simple future | The valve will close. | Approved |
| Infinitive | Turn the knob to close it. | Approved |
| Past participle as an adjective | the closed valve | Approved |
| Progressive (-ing) | The valve is closing. | Not approved |
| Perfect | The valve has closed. | Not approved |
| Passive in a procedure | The valve must be closed. | Not approved |

- Use an -ing form only inside a technical name, for example "landing gear".
- A description can use the passive only when the doer is not known.

## Sentences

- Write an instruction as a command: "Make sure that the switch is off."
- A safety instruction starts with the command. Then it gives the risk: "Do not touch the unit until it is cool. Hot parts can cause injury."
- Warning means a risk of injury. Caution means a risk of damage.
- Use the active voice in procedures.
- Use the same word for the same thing every time.
- Do not leave out "the", "a" or "this".
- Use a vertical list for complex text.

## Words

An approved word has one meaning and one part of speech. "Close" is a verb. It does not mean "near".

| Not approved | Use |
| --- | --- |
| ensure | make sure |
| commence | start |
| prior to | before |
| replenish | fill |
| utilize | use |
| approximately | about |
| in order to | to |
| close (adjective) | near |

## Check before you send

1. Count the words in each sentence against the limits.
2. Find each -ing, "has", "have", "is ...ed" and "be ...ed". Change it to an approved form.
3. Find each word in the table above. Change it.
4. Make sure that each sentence has one fact or one instruction.
