# Explainer

Public copy of the Arc Forge explainer skill: visual explainer pages, diagrams first, every part opens a definition. Any agent can read it: start with [SKILL.md](SKILL.md).

- [references/chart-lab.html](references/chart-lab.html): every rated chart kind, drawn on one subject (example data).
- [examples/starter.html](examples/starter.html): copy it to start a page.
- [examples/explainer-kit.html](examples/explainer-kit.html): a full page that uses every renderer.

Generated by `scripts/export-public` in the private `arcforgelabs/tools` repo (`skills/explainer`; the plugin's PROVENANCE.json names the commit). Do not edit this folder by hand: change the source and export again. Required authoring helpers are included: `scripts/bundle` (Node.js), `scripts/check` and `scripts/record-walkthrough` (Playwright; set `CHROMIUM_PATH` for an installed Chromium). Tier A recording also requires Xvfb and ffmpeg. Theme generation and release tooling stay in the source repo.
